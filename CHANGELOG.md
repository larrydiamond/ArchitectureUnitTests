# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/2.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

For this project the stable interface is the public API of the library: the `ArchitectureRule` enum constants (which
users reference to exclude rules), `ArchitectureUnitTest` and the rules tree classes.

## [Unreleased]

### Added

- `SPRING_PROXIED_METHODS_SHOULD_NOT_BE_CALLED_INSIDE_SAME_CLASS`: calling a method annotated with `@Transactional`,
  `@Cacheable`, `@CachePut`, `@CacheEvict`, `@Caching`, `@Async`, `@PreAuthorize`, `@PostAuthorize` or `@Secured` from
  another method in the same class bypasses the Spring proxy, so the annotation has no effect. Calls made through a
  self-injected reference are allowed.
- `METHODS_WITH_THE_ASYNC_ANNOTATION_MUST_BE_PUBLIC`: Spring creates proxies around `@Async` methods, so non-public
  ones are not executed asynchronously.
- `DO_NOT_CONSTRUCT_APACHE_COMMONS_LANG3_TUPLE_CLASSES`: `Pair`, `Triple` and friends hide what the object represents;
  use a real class instead.
- Every rule now has a category, a since-version and tags. A navigable rules tree (HTML and JSON) is generated by
  `./gradlew rulesTree` and is available in code through `RuleTree.byCategory`, `byTag` and `bySince`.

### Changed

- Calls to a proxied method made through a self-injected reference (for example a `@Lazy` field of the class's own type)
  are no longer reported. A plain `this.method()` call is still reported, even in a class that also self-injects.

### Removed

- **Breaking:** the `SPRING_CACHEABLE_METHODS_SHOULD_NOT_BE_CALLED_INSIDE_SAME_CLASS` rule. `@Cacheable` is now checked
  by `SPRING_PROXIED_METHODS_SHOULD_NOT_BE_CALLED_INSIDE_SAME_CLASS`. If you exclude the old rule, exclude the new one
  instead; note that this switches off the check for every annotation the new rule covers.

## [5.0.0] - 2025-11-16

### Added

- `PREFER_CAFFEINE_OVER_GUAVA_CACHING`: prefer Caffeine over Google Guava caching.
- `GUAVA_EVENTBUS_SHOULD_NOT_BE_USED`: Guava discourages the use of its `EventBus`.
- `SPRING_CACHEABLE_METHODS_SHOULD_NOT_BE_CALLED_INSIDE_SAME_CLASS`: calling a cacheable method from another method in
  the same class bypasses the caching.

## [4.0.2] - 2025-05-20

### Fixed

- The check for private JUnit 5 tests (`JUNIT5_TESTS_CANT_BE_PRIVATE`).

## [4.0.1] - 2025-05-19

### Fixed

- A bug found when running the newest code through other projects.

## [4.0.0] - 2025-05-18

### Added

- Rules that catch JUnit 5 tests that will never run, such as `JUNIT5_TESTS_CANT_BE_STATIC`.
- More Spring Boot rules, such as `SPRING_BOOT_REQUESTMAPPING_CONTROLLER`, `SPRING_BOOT_GETMAPPING_CONTROLLER`,
  `SPRING_BOOT_POSTMAPPING_CONTROLLER` and the `JPA_COUPLING_RESTFUL_POST_MAPPINGS` rules.

## [3.0.0] - 2025-05-03

### Added

- OpenRewrite recipes in the build.

## [2.0.0] - 2024-08-20

### Added

- Many new architecture rules, including the Spring Boot layering and JPA coupling rules.

## [1.1.0] - 2024-07-19

### Added

- Rules for `RequestMapping` safety.

## [1.0.0] - 2024-07-16

### Added

- `JPA_COUPLING_RESTFUL_GET_MAPPINGS`
- `IS_METHODS_RETURN_PRIMITIVE_BOOLEAN`
- `RESTATE_ISNOT_METHODS_AS_POSITIVE`
- `OPTIONAL_NOT_NULLABLE`

## [0.1.0] - 2024-04-27

Initial release.
